# Lerncoaching · Gesprächsführer

A German-language learning coaching conversation guide for educators conducting structured one-on-one coaching sessions with students.

## Key Technologies

- **TanStack Start** (React, file-based routing)
- **Tailwind CSS v4**
- **Fraunces** (serif display font) + **DM Sans** (body font)
- Deployed on **Netlify**

## Features

- **Student management** — add/remove students, switch between them mid-session
- **5-phase conversation guide** — Einstieg, Analyse, Ziele, Strategien, Reflexion
- **Session timer** — start/pause/reset
- **Question highlighting** — click questions to mark them as used
- **Per-phase notes** — notes stored per student and per phase
- **Session overview** — live summary of highlights, duration, and progress
- **Help modal** — onboarding instructions

## Run Locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:3000`.
